# Atulanshi Sharma — Career Portfolio

A responsive, single-page personal career showcase.

## Files
- `index.html` — website structure/content
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation and scroll reveals
- `assets/profile.jpg` — supplied profile image
- `assets/Atulanshi-Sharma-Resume-2026.pdf` — supplied resume

## Run locally
Open `index.html` in a browser.

For best results with local development, use any simple static server (for example VS Code Live Server).

## Deploy
This is a static website and can be deployed to GitHub Pages, Netlify, Vercel, or any standard static hosting service.
